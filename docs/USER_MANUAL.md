## 简介

**AI-ATG (AI-Automatic Test Generation)** 是一个基于AI的智能测试平台，帮助测试团队：

- 🤖 **智能生成**：使用AI自动生成测试用例
- ⚡ **自动执行**：自动化执行测试并生成报告
- 📊 **数据分析**：可视化测试数据和趋势分析
- 🔗 **CI/CD集成**：与GitLab无缝集成

## 快速开始

### 1. 系统登录

访问系统地址：`http://localhost:5173`

**默认管理员账号**：
- 用户名：`admin`

## 功能使用指南

### 用户管理

#### 注册新用户

1. 点击登录页面的"注册账号"
2. 填写用户名、密码、邮箱等信息
3. 点击"注册"按钮
4. 使用新账号登录

#### 管理用户

**仅管理员可用**

1. 进入"用户管理"页面
2. 查看所有用户列表
3. 可以启用/禁用用户
4. 可以删除用户

---

### 项目管理

#### 创建项目

1. 进入"项目管理"
2. 点击"创建项目"
3. 填写项目名称和描述
4. 创建者自动成为项目管理员

#### 成员管理

1. 在项目列表中点击"成员管理"
2. 点击"添加成员"
3. 输入用户ID和角色
4. 角色说明：
   - **管理员**：可以管理项目和成员
   - **成员**：可以参与项目工作

---

### 需求管理

#### 创建需求

1. 进入"需求管理"页面
2. 点击"创建需求"按钮
3. 填写需求信息：
   - 需求标题
   - 需求描述
   - 优先级（高/中/低）
   - 附件（可选）
4. 点击"提交"

#### 查看需求详情

1. 在需求列表点击"查看"
2. 查看需求完整信息
3. 查看关联的测试用例
4. 下载附件

#### 搜索和筛选

- 按标题搜索
- 按状态筛选
- 按优先级筛选

---

### 测试用例管理

#### 创建测试用例

1. 进入"测试用例"页面
2. 点击"创建用例"
3. 填写用例信息
4. 添加测试步骤：
   - 步骤描述
   - 预期结果
   - 步骤顺序
5. 保存用例

#### 创建测试套件

1. 点击"测试套件"标签
2. 点击"创建套件"
3. 填写套件名称和描述
4. 将用例添加到套件

#### 批量操作

- 批量删除用例
- 批量导出用例
- 批量修改状态

---

### AI 测试用例生成

#### 配置AI服务

1. 进入"AI配置"页面
2. 选择AI提供商：
   - DeepSeek
   - 阿里千问
   - 智谱AI
3. 填写API密钥
4. 保存配置

#### 生成测试用例

1. 进入"AI生成"页面
2. 选择需求
3. 选择AI提供商
4. 点击"生成测试用例"
5. 等待AI生成（约5-10秒）
6. 查看生成结果
7. 保存到测试用例库

#### 查看生成历史

1. 点击"生成历史"标签
2. 查看所有生成记录
3. 可以重新查看生成内容

---

### 测试执行

#### 执行测试

1. 进入"测试执行"页面
2. 点击"开始执行"
3. 选择配置：
   - 测试类型（API/UI/性能）
   - 测试套件
   - 执行环境
4. 点击"开始执行"
5. 查看执行进度

#### 查看执行详情

1. 在执行列表点击"查看详情"
2. 查看执行摘要：
   - 总用例数
   - 通过/失败数
   - 执行时长
3. 查看每个用例的执行结果
4. 查看执行日志

#### 停止执行

- 对于进行中的执行，可以点击"停止"按钮

---

### 测试报告

#### 生成报告

1. 进入"测试报告"页面
2. 选择执行记录
3. 系统自动生成报告

#### 查看报告

1. 在报告列表点击"查看详情"
2. 查看报告内容：
   - 执行摘要
   - 结果分布图（饼图）
   - 执行时长图（柱状图）
   - 详细结果列表

#### 导出报告

1. 点击"导出HTML"按钮
2. 生成独立的HTML报告
3. 可以分享给团队成员

#### 查看统计

1. 点击"统计分析"
2. 查看整体统计：
   - 总执行次数
   - 通过率
   - 失败率
3. 查看趋势图
4. 查看Top 10失败用例

### GitLab 集成

#### 配置GitLab

1. 进入"GitLab集成"页面
2. 填写GitLab信息：
   - GitLab URL
   - Access Token
   - 分支名称
3. 保存配置
4. 复制生成的Webhook URL和密钥

#### 在GitLab中配置Webhook

1. 登录GitLab
2. 进入项目设置
3. 选择"Webhooks"
4. 填写：
   - URL：从AI-ATG复制的Webhook URL
   - Secret Token：从AI-ATG复制的密钥
5. 选择触发事件：Push events
6. 保存

#### 查看Webhook记录

1. 点击"Webhook记录"
2. 查看所有接收的事件
3. 查看处理状态和详情

## 常见问题

### Q1: 如何获取AI API密钥？

**DeepSeek**：
- 访问 https://platform.deepseek.com
- 注册账号
- 在API密钥页面创建密钥

**阿里千问**：
- 访问阿里云控制台
- 开通千问服务
- 创建API密钥

**智谱AI**：
- 访问 https://open.bigmodel.cn
- 注册账号
- 获取API密钥

### Q2: AI生成失败怎么办？

**可能原因**：
1. API密钥未配置或无效
2. API调用额度不足
3. 需求描述不够详细
4. 网络连接问题

**解决方法**：
1. 检查AI配置是否正确
2. 确认API密钥有效
3. 完善需求描述
4. 查看生成历史中的错误信息

### Q3: 测试执行一直在运行？

**可能原因**：
1. 后端服务异常
2. 测试用例配置错误
3. 执行超时

**解决方法**：
1. 点击"停止执行"
2. 查看执行日志
3. 检查测试用例配置

### Q4: 报告图表不显示？

**可能原因**：
- ECharts库未安装

**解决方法**：
```bash
cd frontend
npm install echarts --save
```

### Q5: GitLab Webhook不工作？

**检查项**：
1. Webhook URL配置正确
2. Secret Token正确
3. GitLab能访问AI-ATG服务器
4. 查看Webhook记录中的错误信息

### Q6: 如何提升系统性能？

**建议**：
1. 启用Redis缓存
2. 创建数据库索引（执行V10脚本）
3. 调整分页大小
4. 定期清理历史数据
