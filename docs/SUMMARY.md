## 一句话总结

**AI-ATG** 是一个集需求管理、AI测试用例生成、自动化测试执行、报告分析、CI/CD集成于一体的完整智能测试平台。

---

## 核心特性

🤖 **AI驱动** - 三大AI模型智能生成测试用例
⚡ **自动化** - 端到端自动化测试执行
📊 **可视化** - ECharts图表数据分析
🔗 **CI/CD** - GitLab Webhook无缝集成
👥 **协作** - 多项目多成员团队支持
⚡ **高性能** - 35索引+Redis缓存优化

## 技术栈

**后端**: Spring Boot 3.2.1 + MyBatis Plus + MySQL + Redis + MinIO

**前端**: Vue 3.4 + Element Plus + Pinia + ECharts

**AI**: DeepSeek + 阿里千问 + 智谱AI

**基础设施**: Docker + MySQL 8.0 + Redis 7.x

---

## 快速开始

```bash
# 1. 启动基础设施
docker-compose up -d mysql redis minio

# 2. 启动后端
cd backend && mvn spring-boot:run

# 3. 启动前端
cd frontend && npm install && npm run dev

# 4. 访问系统
http://localhost:5173
```

**默认账号**: admin / admin123
